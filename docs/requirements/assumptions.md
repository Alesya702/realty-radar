# Временные допущения

Допущения, принятые, чтобы двигаться дальше без ответов бизнеса. Каждое допущение:

- явно помечено и по возможности ссылается на открытый вопрос из [open-questions.md](open-questions.md);
- может быть пересмотрено; при пересмотре обновите статус и затронутые документы и код;
- **не является бизнес-требованием**. В коде допущения реализуются так, чтобы их было легко
  изменить: через конфигурацию, справочник или отдельную функцию, а не через разбросанные
  константы.

Статусы: `действует` · `подтверждено` (стало требованием) · `отменено`.
